어디까지 확인했나요?

  • 이 화면은 실제 기관에 읽기 전용 요청을 보냅니다.
  • 원천에 적힌 내용과 사실 검증은 다릅니다.
  • 일부 행을 조회하며 전체 자료를 집계하지 않습니다.
  • 자유어 검색과 기관 간 자동 연결은 아직 지원하지 않습니다.

기존 공식 서비스도 활용하세요

공식 MCP 안내 ↗
내 AI에서 이 연결 도구 쓰기

프로젝트 폴더에서 npm run config:mcp를 실행하면 현재 PC에 맞는 설정을 출력합니다. 로컬 stdio MCP를 지원하는 클라이언트에 등록합니다.

예시 질문: “사용할 수 있는 공공자료를 보여줘. 국립중앙도서관 예시에서 자료 하나를 골라 원문 속성과 출처를 알려줘.”

설정 파일을 자동 변경하지 않습니다. 원격 커넥터 입력란에는 localhost 주소를 넣지 않습니다.

기관별 이용 조건을 확인해 주세요. 조회 결과를 그대로 재배포해도 된다는 뜻은 아닙니다.
